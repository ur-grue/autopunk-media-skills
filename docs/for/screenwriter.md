# For Screenwriters

[← Back to README](../../README.md)

You write scripts — features, pilots, shorts. This library covers the whole arc: from a premise you can barely articulate to a production-ready package a producer can act on. Below is a curated path through the skills most screenwriters reach for, in the order a project actually moves.

**New here?** You don't need to install anything. Open [claude.ai](https://claude.ai), open the skill file you want, and paste its text into Claude with your own material. That's it.

---

## 1. Develop the concept

- [logline-writer](../../skills/screenwriting/development/logline-writer/SKILL.md) — distil your idea into a single sentence that sells the movie
- [treatment-writer](../../skills/screenwriting/development/treatment-writer/SKILL.md) — the 5–10 page document producers and financiers ask for
- [character-profile-writer](../../skills/screenwriting/development/character-profile-writer/SKILL.md) — psychology, backstory, want, need, flaw, wound, voice

See also: [logline-creator](../../skills/tv-documentary/development/logline-creator/SKILL.md) (documentary variant — useful for projects based on true events)

## 2. Structure the story

- [beat-sheet-builder](../../skills/screenwriting/development/beat-sheet-builder/SKILL.md) — a 15-beat story map across three acts, from premise to resolution

## 3. Write the script

- [scene-writer](../../skills/screenwriting/scripting/scene-writer/SKILL.md) — slugline, action, dialogue in industry-standard format, ready to drop into a draft
- [dialogue-polisher](../../skills/screenwriting/scripting/dialogue-polisher/SKILL.md) — sharpen subtext, differentiate voices, cut on-the-nose writing

See also: [pull-quote-selector](../../skills/writing/articles/pull-quote-selector/SKILL.md) (pick the strongest lines from a scene for a table read or pitch document)

## 4. Revise and get coverage

- [coverage-report-writer](../../skills/screenwriting/revision/coverage-report-writer/SKILL.md) — logline, synopsis, scores, and written evaluation in the format readers and execs use
- [script-notes-writer](../../skills/screenwriting/revision/script-notes-writer/SKILL.md) — structural, character, and scene-level editorial notes on a specific draft

## 5. Package for production

- [one-pager-writer](../../skills/screenwriting/production/one-pager-writer/SKILL.md) — logline, synopsis, tone references, and writer positioning on a single page
- [elevator-pitch-writer](../../skills/media-business/pitching/elevator-pitch-writer/SKILL.md) — a tight 60-second verbal pitch for meetings and festivals

---

**Start with:** [logline-writer](../../skills/screenwriting/development/logline-writer/SKILL.md) → [beat-sheet-builder](../../skills/screenwriting/development/beat-sheet-builder/SKILL.md). In five minutes you'll have a logline and a full structural map you can write from.
